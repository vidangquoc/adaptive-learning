# Official Knowledge

This directory contains canonical learning material promoted from approved candidate knowledge.

Organization:

```text
knowledge/
└── <book>/
    └── <unit>/
        └── <section>/
            └── knowledge-atoms.*
```

Official knowledge is produced by copy-and-promote from candidates with an explicit `APPROVE` decision. Candidate data is never moved or deleted as part of promotion.

Downstream competency, diagnostic, challenge, and adaptive-learning systems should consume this canonical layer.
