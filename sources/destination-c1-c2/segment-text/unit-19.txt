• 
So and such can also be used in various ways without a that clause. 
✓ There's so much crime around here these days. ✓ Politics is so boring' ✓ You're such a bully! 
• We only use too to describe something that is more than necessary and which has a negative effect. It is not the 
same as very, really, extremely, etc. 
• 
It is not necessary to add an extra object in sentences such as the following: 
X T/lis p10b/e11, see111s to be too o'iffico/t fa, tlle11, to solve it. 
• 
Enough usually comes before nouns and after adjectives and adverbs.
