# PTNK Vocabulary Profile

The working profile focuses on:

- advanced general vocabulary
- idioms and fixed expressions
- phrasal verbs
- collocations
- word formation and word families
- academic/general reading vocabulary
- topic vocabulary used for contextual reading

Observed PTNK materials suggest that specialized passages may appear, but preparation should prioritize transferable English competence over memorizing large domain-specific glossaries.

## CEFR labels

Use one of:

- `C1` / `C2` — verified against a reliable CEFR/EVP source
- `approx-C1` / `approx-C2` — working estimate, not yet verified
- `unverified` — no CEFR level assigned yet

Never invent an exact EVP level when it has not been checked.
