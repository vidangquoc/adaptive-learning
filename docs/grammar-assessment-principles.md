# Grammar Assessment Principles

> This document records the grammar-specific learning-material rules discovered during prototype validation. These rules must be treated as an extension of the project's canonical learning-material principles.

## 1. Grammar is a modeling problem, not a transcription problem

A grammar knowledge atom must model more than a textbook heading or surface form. Where relevant, represent:

- form;
- meaning;
- function;
- constraints;
- discourse context;
- contrasts with nearby constructions.

The goal is the smallest useful unit that can support instruction, diagnosis, and valid assessment.

## 2. Separate grammaticality from interpretation

For grammar assessment, distinguish:

```text
grammaticality
contextual appropriateness
intended meaning
```

A candidate answer can be grammatical while expressing a different interpretation from the one intended by the item. Therefore "the textbook intended B" is not sufficient evidence that B is uniquely correct.

## 3. Answer uniqueness is mandatory

Before a grammar question enters the canonical question bank, evaluate every candidate answer:

1. Is it grammatical?
2. What interpretation does it permit?
3. Does the supplied context license or exclude that interpretation?
4. Is exactly one candidate compatible with the intended meaning/task?

If two or more answers are grammatical and compatible with the context, **reject or rewrite the question**.

Example of an invalid item:

```text
When I arrived at the lab, Sarah ___ the results.
A. checked
B. was checking
C. had checked
D. has checked
```

Without additional context, both `was checking` and `had checked` can describe coherent situations. The item therefore lacks a uniquely defensible answer.

A valid rewrite must encode the intended interpretation explicitly, e.g. with context equivalent to "was still checking" or "had already finished checking" when that contrast is what is being assessed.

## 4. Answer keys do not override ambiguity

A source answer key is evidence about the author's intended answer, not proof that the question is objectively valid.

If independent review demonstrates another grammatical and contextually compatible answer, the item must be flagged for review rather than forcing the learner to accept the key.

## 5. Prefer context-rich and contrastive assessment

When several constructions are close competitors, prefer formats that make the semantic/discourse distinction explicit:

- context-conditioned multiple choice;
- contrast selection with explicit meaning cues;
- error identification with objectively constrained errors;
- meaning-preserving transformation;
- controlled production;
- explanation/justification when the competency requires it.

Do not force every grammar distinction into a single-answer MCQ.

## 6. Grammar quality gate

```text
Question generated
       ↓
Check grammaticality of all candidates
       ↓
Check interpretation of each grammatical candidate
       ↓
Does context license exactly one answer?
       ↓
   NO ─────────→ REJECT / REWRITE
   YES
       ↓
Check knowledge-atom linkage
       ↓
Check competency / skill
       ↓
      ACCEPT
```

## 7. Preserve uncertainty

If the source does not provide enough evidence to determine a rule, contrast, or constraint, do not invent one. Preserve the source evidence and mark the modeled interpretation as pending/review-needed.

> **Accuracy and assessment validity take precedence over extraction volume and apparent completeness.**

## 8. Non-negotiable rule

> **A grammar question is invalid if multiple answers are grammatical and contextually compatible with the intended meaning. Reject or rewrite it.**

This applies to both source-derived and generated questions.
